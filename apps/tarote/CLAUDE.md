# Tarote - AI 타로 리딩 서비스

## 📋 서비스 개요
AI 기술을 활용한 온라인 타로 카드 리딩 서비스입니다.

## 🎯 비즈니스 목표
- **접근성**: 누구나 쉽게 타로 리딩 경험
- **즉시성**: 24시간 언제든 즉석 해석
- **개인화**: AI 맞춤형 해석 제공

## 🔄 수익 모델
- **프리미엄 전환**: 비회원 요청 → 회원 결과 확인
- **리텐션**: 히스토리 제공으로 재방문 유도

## 👤 타겟 사용자
- 타로 초보자
- 일상 고민자
- 영성 탐구자

## 🎪 핵심 기능
1. **질문 작성** (500자 제한)
2. **카드 선택** (직감적으로 3장)
3. **AI 해석** (비동기 처리)
4. **결과 확인** (회원만 가능)

## 🔄 사용자 여정
```
홈 → 질문 → 카드선택 → AI처리 → 결과(회원가입 유도) → 확인
```
