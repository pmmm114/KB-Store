# Tarote Project Overview

## 🎯 프로젝트 개요

AI 기반 타로 리딩 서비스로, 사용자가 질문을 입력하면 타로 카드를 선택하고 AI가 해석을 제공하는 웹 애플리케이션입니다.

## 🎪 핵심 기능

1. **질문 입력**: 사용자가 타로에게 물어보고 싶은 질문 입력
2. **카드 선택**: 3장의 타로 카드 선택
3. **AI 해석**: 선택된 카드와 질문을 바탕으로 AI가 해석 제공
4. **결과 공유**: 해석 결과 저장 및 공유

## 🔄 사용자 플로우

```
질문 입력 → 카드 선택 → AI 해석 → 결과 표시 → 공유/저장
```

## 📱 주요 페이지

- **홈페이지** (`/`): 서비스 소개 및 시작
- **리딩 페이지** (`/reading`): 통합 타로 리딩 경험
  - Question Step: 질문 입력
  - Select Step: 카드 선택
- **결과 페이지** (`/result`): 통합 타로 리딩 경험
  - 요청에 따라 로딩이 필요한 경우 로딩UI를 표시
  - Result Step: AI 해석 결과 표시
