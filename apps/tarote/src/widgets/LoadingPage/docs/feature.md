# LoadingPage Feature Specification

## 📋 개요

**LoadingPage**는 타로 결과 페이지(`/result`)에서 AI 해석 결과를 받아오는 동안 사용자가 대기하는 시간에 표시되는 로딩 UI 위젯입니다.

상위 docs/feature.md에서 정의한 "결과 페이지에서 요청에 따라 로딩이 필요한 경우 로딩UI를 표시" 기능을 구현하며, 타로 리딩 서비스의 신비로운 분위기를 유지하면서 사용자에게 시각적으로 매력적인 대기 경험을 제공합니다.

**상위 기능과의 연관성:**

- 타로 리딩 플로우의 마지막 단계에서 사용자 경험 향상
- AI 해석 결과 생성 대기 시간의 긍정적인 사용자 경험 제공
- 타로 리딩 서비스의 신비로운 브랜드 이미지 강화

## 🎯 핵심 기능

### 1. 크리스탈 볼 로딩 애니메이션

**목적**: 타로 리딩 서비스의 신비로운 분위기와 일치하는 시각적 피드백 제공

**기능 상세:**

- **크리스탈 볼 코어**: 반투명한 크리스탈 볼 형태의 중앙 애니메이션
- **글로우 이펙트**: 크리스탈 볼 주변의 빛나는 후광 애니메이션
- **색상 변화**: `hue-rotate`를 통한 색상 순환 애니메이션
- **브리드니스 변화**: 밝기 변화를 통한 생동감 있는 시각 효과

### 2. 무한 애니메이션 시스템

**목적**: AI 처리 시간이 불확실한 상황에서도 자연스러운 대기 경험 제공

**기능 상세:**

- **코어 애니메이션**: 4.5초 주기의 `coreColorAnim`으로 색상/밝기 변화
- **글로우 애니메이션**: 5.1초 주기의 `glowColor`로 후광 이펙트 변화
- **무한 반복**: `infinite alternate`를 통한 부드러운 순환
- **독립적 애니메이션**: 코어와 글로우가 서로 다른 주기로 동작하여 복합적 시각 효과

### 3. 타로 테마 시각 디자인

**목적**: 타로 리딩 서비스와 일관된 브랜드 경험 제공

**기능 상세:**

- **색상 팔레트**: 보라색(#b39ddb)과 시안(#80deea) 기반의 신비로운 색조
- **블러 효과**: `backdrop-filter`와 `filter: blur()`를 통한 몽환적 분위기
- **그라데이션**: 방사형 그라데이션을 통한 크리스탈 볼의 사실적 표현
- **다크 배경**: `bg-slate-800`으로 크리스탈 볼의 빛을 강조

### 4. 사용자 안내 메시지

**목적**: 현재 상태에 대한 명확한 정보 제공

**기능 상세:**

- **로딩 텍스트**: "로딩 중입니다..." 메시지 표시
- **텍스트 스타일**: 흰색 텍스트로 가독성 확보
- **배치**: 크리스탈 볼 하단에 적절한 간격으로 배치

## 🎨 UI/UX 구조

### 스타일링 구조

**CSS 모듈 기반:**

- `.loadingPage`: 전체 레이아웃 컨테이너 (fullscreen, flex center)
- `.crystalBallWrapper`: 크리스탈 볼 애니메이션의 상대적 위치 컨테이너
- `.crystalBallCore`: 메인 크리스탈 볼 스타일 (그라데이션, 애니메이션)
- `.crystalBallGlow`: 후광 이펙트 스타일 (블러, 색상 변화)
- `.loadingText`: 로딩 메시지 텍스트 스타일

**애니메이션 구조:**

- `@keyframes coreColorAnim`: 크리스탈 볼 코어의 색상/밝기 변화
- `@keyframes glowColor`: 후광 이펙트의 블러/색상/투명도 변화

### 접근성 고려사항

**시각적 접근성:**

- 고대비 텍스트로 가독성 확보
- 애니메이션 선호도 고려 필요 (`prefers-reduced-motion` 미적용)

**성능 최적화:**

- CSS 애니메이션 사용으로 GPU 가속 활용
- 변형(transform) 기반 애니메이션으로 리플로우 최소화

## 🧪 테스트 시나리오

### 기본 기능 테스트

1. **렌더링 확인**: LoadingPage 컴포넌트가 올바르게 렌더링되는지
2. **애니메이션 동작**: 크리스탈 볼과 글로우 애니메이션이 정상 작동하는지
3. **텍스트 표시**: "로딩 중입니다..." 메시지가 올바르게 표시되는지
4. **스타일 적용**: CSS 모듈 스타일이 정상적으로 적용되는지

### 성능 테스트

1. **애니메이션 성능**: 장시간 동작 시 성능 저하 없이 부드러운 애니메이션 유지
2. **메모리 사용량**: 메모리 누수 없이 정상 동작
3. **CPU 사용률**: 적절한 CPU 사용률 유지

### 브라우저 호환성 테스트

1. **CSS 지원**: backdrop-filter, CSS 애니메이션 등의 브라우저 지원 확인
2. **성능 차이**: 다양한 브라우저에서의 애니메이션 성능 차이 확인
