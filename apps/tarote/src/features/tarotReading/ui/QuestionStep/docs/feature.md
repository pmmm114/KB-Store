# QuestionStep Feature Specification

## 📋 개요

`reading` 페이지의 질문 입력 단계를 담당하는 컴포넌트입니다.
`reading` 페이지의 첫 번째 단계로서, 사용자가 질문을 입력하는 기능을 제공합니다.

### 상위 기능과의 연관성

- 전체 타로 reading flow의 첫 번째 단계 (질문 입력 → 카드 선택 → AI 해석)
- `reading` 페이지의 Step 관리 시스템 내에서 첫 번째 Step 역할
- 사용자가 타로에게 물어보고 싶은 질문을 수집하는 핵심 인터페이스

## 🎯 핵심 기능

### 1. 질문 텍스트 입력

- **목적**: 상위 docs/feature.md에서 정의한 "질문 입력" 기능 구현
- **입력 방식**: contentEditable div 사용 (ChatGPT 스타일 UX)
- **제약사항**:
  - 최대 500자 제한
  - 순수 텍스트만 허용 (HTML 태그 제거)
  - 빈 질문 제출 불가
- **사용자 경험**:
  - 실시간 문자 수 카운트 표시
  - 제한 초과 시 시각적 경고 (빨간색 표시)
  - 플레이스홀더 텍스트 제공

### 2. 텍스트 편집 기능

- **줄바꿈**: Shift+Enter로 줄바꿈 지원
- **제출**: Enter 키로 바로 제출
- **붙여넣기**:
  - 순수 텍스트만 붙여넣기 허용
  - 글자 수 제한 내에서만 허용
  - 커서 위치 유지
- **텍스트 관리**: 하나의 TextNode 유지하여 일관성 보장

### 3. 상태 관리

- **전역 상태**: useTarotReading 훅을 통한 질문 상태 저장
- **로컬 상태**: 실시간 입력 상태 관리 (localQuestion)
- **상태 동기화**: 전역 상태와 로컬 상태 간 양방향 동기화

### 4. 다음 단계 전환

- **전환 조건**: 유효한 질문 입력 후 활성화
- **전환 방식**: onNextAction props를 통한 부모 컴포넌트로 제어권 전달
- **데이터 전달**: 입력된 질문을 전역 상태에 저장하여 다음 단계에서 활용

## 🎨 UI/UX 구조

### 스타일링 구조

**CSS 모듈 기반:**

- `.questionStep`: 전체 컨테이너 (flex, 중앙 정렬, 패딩)
- `.form`: 폼 래퍼 (최대 너비 제한, 컬럼 레이아웃)
- `.title`: 제목 스타일 (중앙 정렬, 큰 폰트, 굵은 글씨)
- `.inputContainer`: 입력 영역 컨테이너 (상대 위치)
- `.contentEditableInput`: 실제 입력 필드 (둥근 모서리, 보더, 포커스 효과)
- `.characterCount`: 글자 수 카운터 (우하단 절대 위치)
- `.overLimit`: 글자 수 초과 시 경고 스타일 (빨간색)
- `.actions`: 버튼 영역 (컬럼 레이아웃)
- `.nextButton`: 다음 단계 버튼 (파란색, 호버 효과, 비활성화 상태)

## 🧪 테스트 시나리오

### 기본 입력 테스트

- 정상적인 질문 입력 후 제출 가능 여부
- 빈 질문 입력 시 제출 버튼 비활성화
- 500자 제한 동작 확인

### 키보드 인터랙션 테스트

- Enter 키로 제출 기능
- Shift+Enter로 줄바꿈 기능
- 글자 수 초과 시 Enter 키 제출 차단

### 붙여넣기 테스트

- 순수 텍스트 붙여넣기 동작
- HTML 태그 포함 텍스트 붙여넣기 시 태그 제거
- 글자 수 제한을 초과하는 텍스트 붙여넣기 차단
- 커서 위치 유지 확인

### 상태 관리 테스트

- 로컬 상태와 전역 상태 동기화
- 컴포넌트 재마운트 시 상태 복원
- 다음 단계 진행 시 상태 전달

## 🔗 의존성

### 내부 의존성

- `useTarotReading`: 타로 리딩 전역 상태 관리 훅
- `QuestionStep.module.css`: 컴포넌트 전용 스타일시트

### 외부 의존성

- `React`: useState, useEffect 훅 사용
- `Next.js`: 'use client' 디렉티브를 통한 클라이언트 컴포넌트

## 📋 검증 규칙

- **필수 입력**: 빈 문자열 또는 공백만 있는 경우 제출 불가
- **길이 제한**: 500자 초과 시 제출 불가 및 시각적 경고
- **텍스트 순수성**: HTML 태그나 특수 포맷 제거하여 순수 텍스트만 유지

## 📝 개선 항목

### 단기 개선사항

- **접근성 향상**: ARIA 레이블 및 키보드 네비게이션 개선
- **사용자 경험**: 입력 중 실시간 저장 기능 (드래프트)
- **에러 처리**: 네트워크 오류 시 로컬 상태 보존 메커니즘

### 장기 개선사항

- **AI 지원**: 질문 작성 도움말 또는 예시 제안 기능
- **다국어 지원**: 다양한 언어로 질문 입력 지원
- **음성 입력**: 음성을 텍스트로 변환하는 입력 방식 추가
- **질문 히스토리**: 이전에 입력한 질문들을 기록하고 재사용할 수 있는 기능
