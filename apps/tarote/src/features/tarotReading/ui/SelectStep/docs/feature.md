# SelectStep Feature Specification

## 📋 개요

**SelectStep**은 타로 리딩의 카드 선택 단계를 담당하는 UI 컴포넌트입니다.
`reading` 페이지의 두 번째 단계로서, 사용자가 입력한 질문을 바탕으로 3장의 타로 카드를 선택하는 핵심 기능을 제공합니다.

## 🎯 핵심 기능

### 1. 질문 요약 표시 (Question Summary)

**목적**: 사용자가 이전 단계에서 입력한 질문을 상단에 요약 표시

**기능 상세:**

- Question Step에서 저장된 질문 텍스트를 `useTarotReadingStore`에서 조회
- 시각적으로 구분되는 요약 카드 형태로 표시
- 질문 내용이 길 경우 자동 줄바꿈 처리
- 질문 수정을 위한 "이전 단계로 돌아가기" 기능 제공

### 2. 단계 네비게이션 (Step Navigation)

**목적**: 이전 단계로의 자유로운 이동을 통한 사용자 경험 향상

**기능 상세:**

- **이전 단계 이동**: `onPrev` prop을 통해 Question Step으로 복귀
- **상태 유지**: 이동 시 현재까지 선택한 카드 정보는 유지되지 않음 (초기화)

### 3. 카드 선택 시스템 (Card Selection)

**목적**: 상위 docs/feature.md에서 정의한 "3장의 타로 카드 선택" 핵심 기능 구현

**기능 상세:**

- **카드 선택 위젯**: `CardSelectionSection` 위젯을 통한 카드 인터랙션
- **선택 제한**: 정확히 3장의 카드만 선택 가능
- **완료 조건**: 3장 선택 완료 시에만 결과 페이지로 이동 허용
- **상태 저장**: 선택된 카드 ID를 Zustand 스토어에 저장

### 4. 결과 페이지 이동 (Result Navigation)

**목적**: 카드 선택 완료 후 AI 해석을 위한 결과 페이지로의 자연스러운 전환

**기능 상세:**

- **완료 조건 검증**: 정확히 3장의 카드가 선택되었는지 확인
- **상태 저장**: `setSelectedCards()`를 통해 선택된 카드 ID 배열 저장
- **페이지 이동**: Next.js router를 통한 `/result` 페이지로 이동
- **데이터 전달**: Zustand 스토어를 통해 질문과 선택된 카드 정보를 결과 페이지와 공유

## 🎨 UI/UX 구조

### 스타일링 구조

**CSS 모듈 기반:**

- `.selectStep`: 전체 레이아웃 컨테이너 (flex, column)
- `.header`: 상단 질문 요약 영역 (고정 헤더)
- `.questionSummary`: 질문 표시 카드 (회색 배경, 둥근 모서리)
- `.cardSelection`: 카드 선택 영역 (중앙 정렬, 유연한 높이)

**반응형 고려사항:**

- 모바일에서 터치 인터랙션 최적화
- 카드 선택 영역의 스크롤 가능한 구조

## 🧪 테스트 시나리오

### 기본 기능 테스트

1. **질문 표시 확인**: 이전 단계의 질문이 올바르게 표시되는지
2. **이전 단계 이동**: "질문 수정" 버튼 클릭 시 올바른 단계로 이동하는지
3. **카드 선택**: 3장의 카드 선택이 정상적으로 작동하는지
4. **완료 처리**: 3장 선택 완료 시 결과 페이지로 이동하는지

### 예외 상황 테스트

1. **질문 없음**: 질문이 없는 상태에서 접근 시 처리
2. **불완전한 선택**: 3장 미만 선택 시 완료 버튼 비활성화
3. **네트워크 오류**: 페이지 이동 실패 시 오류 처리
