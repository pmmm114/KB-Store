# Reading - UI/UX 요구사항

## 디자인 일관성

### 컬러 팔레트

- **Primary**: 미스터리한 퍼플 톤 (#6B46C1)
- **Secondary**: 블루 톤 (#3B82F6)
- **Background**: 앰버 톤 (#FEF3C7)
- **Text**: 그레이 계열 (#374151)

### 타이포그래피

- **Heading**: 2xl, font-bold
- **Body**: lg, regular
- **Caption**: sm, medium

### 스페이싱

- **Container**: max-w-md, mx-auto
- **Gap**: 6 (1.5rem) 기본 간격
- **Padding**: px-4, py-3 기본 패딩

## 사용자 경험

### 단계별 플로우

- **진행 표시**: 상단에 단계 인디케이터
- **부드러운 전환**: 페이드 인/아웃 애니메이션
- **뒤로가기**: 이전 단계로 돌아가기 버튼

### 질문 입력 (Question Step)

- **입력 경험**: ChatGPT 스타일 contentEditable
- **플레이스홀더**: "질문을 입력하세요" 안내
- **실시간 피드백**: 글자 수 표시, 유효성 검사
- **키보드 지원**: Enter 제출, Shift+Enter 줄바꿈

### 카드 선택 (Select Step)

- **카드 표시**: 부채꼴 형태로 배치
- **선택 피드백**: 선택된 카드 하이라이트
- **진행 표시**: "3장 중 N장 선택됨" 안내

### 결과 표시 (Result Step)

- **로딩 상태**: AI 해석 중 스피너 표시
- **결과 레이아웃**: 질문 → 카드 → 해석 순서
- **액션 버튼**: 새로운 리딩, 결과 공유

## 반응형 디자인

### 모바일 (< 768px)

- **단일 컬럼**: 세로 배치
- **터치 최적화**: 버튼 크기 44px 이상
- **스크롤**: 세로 스크롤만 사용

### 데스크톱 (≥ 768px)

- **중앙 정렬**: 최대 폭 제한
- **호버 효과**: 버튼 및 카드 호버 상태
- **키보드 네비게이션**: Tab 순서 최적화

## 접근성

### ARIA 라벨

- **Step 인디케이터**: aria-label="현재 단계"
- **카드 선택**: aria-label="타로 카드 선택"
- **결과 영역**: aria-live="polite"

### 키보드 네비게이션

- **Tab 순서**: 논리적 탭 순서 유지
- **포커스 표시**: 명확한 포커스 링
- **스크린 리더**: 의미있는 텍스트 제공

### 색상 대비

- **최소 대비**: WCAG AA 기준 준수 (4.5:1)
- **색상 의존 금지**: 색상 외 추가 표시 방법
