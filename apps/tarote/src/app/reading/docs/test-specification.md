## 성능 테스트

### 로딩 성능

- **첫 화면 로딩**: < 2초
- **단계 전환**: < 500ms
- **AI 응답**: < 10초

### 메모리 사용량

- **최대 메모리**: < 50MB
- **메모리 누수**: 없음
- **가비지 컬렉션**: 효율적

## 테스트 실행 전략

### 개발 단계

- **단위 테스트**: 매 커밋마다 실행
- **통합 테스트**: PR 생성 시 실행
- **E2E 테스트**: 주요 기능 변경 시 실행

### 배포 단계

- **전체 테스트**: 배포 전 필수 실행
- **성능 테스트**: 프로덕션 배포 전 실행
- **회귀 테스트**: 정기적 실행 (주 1회)
