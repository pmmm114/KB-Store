# Reading Feature Specification

## 📋 개요

타로 리딩의 핵심 기능을 담당하는 통합 페이지입니다. 상위 docs/feature.md에서 정의한 "질문 입력 → 카드 선택" 플로우를 단일 페이지에서 step 기반으로 구현하며, 카드 선택 완료 후 결과 페이지(`/result`)로 이동합니다.

**상위 기능과의 연관성:**

- 전체 타로 리딩 서비스의 핵심 기능 구현 (질문 입력 + 카드 선택 단계)
- 홈페이지에서 시작된 사용자 여정의 메인 경험 제공
- FSD 아키텍처를 적용한 확장 가능한 구조

## 🎯 핵심 기능

### 1. Step 관리 시스템

- **목적**: 상위 docs/feature.md에서 정의한 단계별 플로우 관리 (Question → Select)
- **단계 구성**:
  - Question Step: 질문 입력
  - Select Step: 카드 선택
- **상태 지속성**: Zustand를 통해 클라이언트에서만 유지
- **네비게이션**: 이전/다음 단계 이동 및 진행률 표시
- **완료 후 이동**: 카드 선택 완료 시 `/result` 페이지로 리다이렉트

### 2. 질문 입력 단계 (Question Step)

- **목적**: 사용자가 타로에게 물어보고 싶은 질문을 입력
- **입력 방식**: contentEditable div 사용 (ChatGPT 스타일)
- **제약사항**:
  - 최대 500자
  - Shift+Enter로 줄바꿈 허용
  - 빈 질문 제출 불가
- **텍스트 관리**: 순수 텍스트만 지원, 하나의 TextNode 유지
- **전환 조건**: 유효한 질문 입력 후 다음 단계로 이동

### 3. 카드 선택 단계 (Select Step)

- **목적**: 상위 docs/feature.md에서 정의한 "3장의 타로 카드 선택" 구현
- **표시 정보**: 이전 단계에서 입력한 질문 요약 표시
- **카드 인터랙션**: 타로 카드 덱에서 3장 선택
- **전환 조건**: 3장 카드 선택 완료 시 결과 페이지(`/result`)로 이동
- **데이터 전달**: 선택된 카드 정보와 질문을 상태로 저장하여 결과 페이지에서 활용

## 🔄 페이지 간 연결

- **진입점**: 홈페이지(`/`)에서 시작
- **종료점**: 카드 선택 완료 후 결과 페이지(`/result`)로 이동
- **상태 공유**: Zustand Persist를 통해 질문과 선택된 카드 정보를 결과 페이지와 공유
